<Subtitle>Date field + select dropdown in one control row</Subtitle>
<Description>
  `DateTextSelect` combines a date picker and a select input so both fields can be managed together.
  It supports required and range validation, configurable date format, and select-driven date
  disabling rules (for example, business days only).
</Description>

## Import

```ts
import { DateTextSelect } from '@gen2fund/gen2verse-ui-library';
import type { DateTextSelectOption } from '@gen2fund/gen2verse-ui-library';
```

## Basic usage

```tsx
import { useState } from 'react';
import { DateTextSelect } from '@gen2fund/gen2verse-ui-library';
import type { DateTextSelectOption } from '@gen2fund/gen2verse-ui-library';

const options: DateTextSelectOption[] = [
  { value: 'business-days', label: 'Business Days' },
  { value: 'calendar-days', label: 'Calendar Days' },
];

export function Example() {
  const [dateValue, setDateValue] = useState<Date | null>(null);
  const [selectValue, setSelectValue] = useState('');

  return (
    <DateTextSelect
      label="Due Date Type"
      dateValue={dateValue}
      onDateChange={setDateValue}
      selectValue={selectValue}
      selectOptions={options}
      onSelectChange={setSelectValue}
    />
  );
}
```

## Connected rule example

```tsx
const shouldDisableDate = (mode: string) => (date: Date) => {
  if (mode !== 'business-days') return false;
  const day = date.getDay();
  return day === 0 || day === 6;
};

<DateTextSelect
  // ...
  selectValue={selectValue}
  onSelectChange={setSelectValue}
  shouldDisableDate={shouldDisableDate(selectValue)}
/>;
```

## Notes

- **Default date placeholder:** `Select Notice Date`.
- **Date format:** set `dateFormat` (for example `dd/MM/yyyy`) to change display/validation format.
- **Validation:** supports `required`, `minDate`, and `maxDate`.
- **Layout behavior:** helper/error text stays in normal flow to avoid overlap.
