<Title>Alert</Title>
<Subtitle>Inline feedback banner for status and validation messaging</Subtitle>
<Description>
  `Alert` wraps MUI `Alert` with Gen2Verse theme-aware styles. It supports four severities (`info`,
  `success`, `warning`, `error`), optional bold title, dismiss button, action slot, and
  `standard`/`filled`/`outlined` variants with controlled or uncontrolled visibility. It also
  supports animated toast-style rendering and a callback API through `AlertToastProvider` +
  `useAlertToast`.
</Description>

## Import

```ts
import { Alert } from '@gen2fund/gen2verse-ui-library';
```

```ts
import { AlertToastProvider, useAlertToast } from '@gen2fund/gen2verse-ui-library';
```

## Basic usage

```tsx
<Alert severity="info" title="Heads up" message="Please review the selected values." />
<Alert severity="success" variant="filled" message="Saved successfully." />
<Alert
  severity="error"
  dismissible
  message="Unable to process request."
  action={<Button size="small">Retry</Button>}
/>
```
