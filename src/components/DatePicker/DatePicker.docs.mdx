<Subtitle>Single date and quick-select date range picker</Subtitle>
<Description>
  `DatePicker` supports two variants: a single date field and a quick-select date range panel with
  presets and optional custom range inputs. It supports required/error states, min/max range
  validation, disabled-date rules, and configurable date format.
</Description>

## Import

```ts
import { DatePicker, DATE_PICKER_VARIANTS } from '@oleg-irchishyn/irchishyn-ui-library';
```

## Basic usage

```tsx
import { useState } from 'react';
import { DatePicker, DATE_PICKER_VARIANTS } from '@oleg-irchishyn/irchishyn-ui-library';

export function Example() {
  const [value, setValue] = useState<Date | null>(null);

  return (
    <DatePicker
      variant={DATE_PICKER_VARIANTS.SINGLE}
      label="Notice Date"
      value={value}
      onChange={setValue}
    />
  );
}
```

## Quick select usage

```tsx
import { useState } from 'react';
import { DatePicker, DATE_PICKER_VARIANTS } from '@oleg-irchishyn/irchishyn-ui-library';
import type { DateRange, QuickSelectOption } from '@oleg-irchishyn/irchishyn-ui-library';

export function QuickSelectExample({ options }: { options: QuickSelectOption[] }) {
  const [value, setValue] = useState<DateRange | QuickSelectOption | null>(null);

  return (
    <DatePicker
      variant={DATE_PICKER_VARIANTS.QUICK_SELECT}
      label="Date Range"
      value={value}
      quickSelectOptions={options}
      onChange={(_resolvedRange, nextValue) => setValue(nextValue)}
    />
  );
}
```

## Notes

- **Default placeholder:** single date uses `Select Notice Date`.
- **Date format:** set `dateFormat` (for example `dd/MM/yyyy`) to change display/validation format.
- **Validation:** `minDate`, `maxDate`, and `required` are supported in both variants.
- **Disable dates:** use `shouldDisableDate={(date) => ...}` for business-day rules.
