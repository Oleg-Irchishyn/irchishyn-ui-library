<Subtitle>Output format, file splitting, and file naming configuration</Subtitle>
<Description>
  `OutputConfigurationPanel` is a reusable panel that combines three optional sections: **Output
  Format** (select one or more formats, e.g. PDF/Word), **File Splitting** (Consolidated File vs
  Split Per Investor), and **File Naming Convention** (preview, token chips, + Add segment, Reset to
  Default). Each section is optional via props. Styling uses MUI palette tokens (`src/tokens.ts`)
  theme tokens so the panel adapts to light/dark theme (AC10). For building custom layouts with the
  same data and validation, use the `useOutputConfigurationPanel` hook.
</Description>

## Import

```ts
import {
  OutputConfigurationPanel,
  OutputFormatSection,
  FileSplittingSection,
  FileNamingSection,
  useOutputConfigurationPanel,
} from '@oleg-irchishyn/irchishyn-ui-library';
```

## Basic usage

Panel with output format only (default selected formats):

```tsx
<OutputConfigurationPanel
  outputFormat={{
    formats: outputFormatItems,
    selectedFormats: ['pdf'],
    onFormatsChange: (ids) => setSelectedFormats(ids),
    minSelected: 1,
  }}
/>
```

With file splitting and file naming:

```tsx
<OutputConfigurationPanel
  outputFormat={{ formats, selectedFormats, onFormatsChange, minSelected: 1 }}
  fileSplitting={{
    splitMode: 'consolidated',
    onSplitModeChange: (mode) => setSplitMode(mode),
  }}
  fileNaming={{
    tokens,
    availableVariables,
    onTokensChange,
    onReset: () => setTokens(defaultTokens),
    previewFileNames,
    subtitle: 'Configure the output file name…',
  }}
/>
```
